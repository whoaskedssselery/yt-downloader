# YT Downloader

Десктопное приложение (Electron + React + TypeScript) для скачивания видео или только аудио
с YouTube по ссылке. Под капотом — [yt-dlp](https://github.com/yt-dlp/yt-dlp) (бинарник
скачивается автоматически при первом запуске) и `ffmpeg` (поставляется вместе с приложением).

## Возможности

- Вставить ссылку → получить список доступных качеств видео и аудиодорожек.
- Скачать видео в выбранном разрешении или только аудио в MP3/M4A/Opus/WAV.
- Выбор папки для сохранения, прогресс-бар, отмена загрузки.

## Разработка

```bash
npm install
npm run dev
```

## Проверка типов

```bash
npm run typecheck
```

## Сборка

```bash
npm run build   # electron-vite build
npm run dist    # + упаковка через electron-builder
```

## Важно

Используйте только для контента, на который у вас есть право на скачивание (собственные видео,
контент с разрешённой лицензией, личное использование в рамках применимого законодательства и
условий использования YouTube).
